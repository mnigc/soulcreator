SVCode (Simple Viewer & Code Editor) is a lightweight, edit-first code editor. Tweaking a config file, skimming a log, editing a script, flipping through a document — a full IDE is overkill and Notepad is too rough. SVCode lives in between: starts in seconds, shows everything the moment it opens, and saves the instant you're done.

## Features

- **Instant start, whole-disk file tree** — No workspace picking, no folder scanning: your entire disk is the workspace on launch. Multi-tab editing with split editor groups, and NAS network shares can be mounted as top-level locations and browsed like local disks.
- **CodeMirror 6 core** — Syntax highlighting for 20+ languages (C/C++, Rust, Go, Java, Python, JS/TS, Vue, SQL, YAML and more), find & replace, word wrap, and persistent font/indent settings.
- **See it as you open it** — Side-by-side Markdown editing with live preview, sandboxed HTML preview, zoomable images and PDFs, and direct .docx / .xlsx / .pptx viewing — then keep editing in the same window.
- **Instant full-disk search built in** — Powered by my WFSearch engine, reading the NTFS MFT directly: ~2 seconds to index a million files, changes visible in real time, wildcards and path matching supported.
- **Session restore** — Tabs, groups, layout, and even unsaved drafts survive restarts; files save back in their original encoding (UTF-8 / UTF-16 / GBK), refusing to silently corrupt unencodable characters.
- **Tiny and effortless** — The whole editor, search engine included, is a ~4.4MB install with ~100MB idle memory; dark/light themes, bilingual UI, and auto-updates.
